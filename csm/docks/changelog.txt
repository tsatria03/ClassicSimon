New in 1.0.
Improved autopilot mode. It no longer says go when a round begins, and when it slips up the game now says the computer failed instead of you failed.
Added a settings menu, reachable from the main menu, where you can turn spoken hints on or off for the current session.
Added spoken hints, which are on by default. The game announces each round number, says go when it is your turn to repeat the sequence, and names each arrow as you press it in learn tones. You'll be able to switch these off in the future.
Updated the readme with clearer instructions on how to play, plus new sections covering difficulty, autopilot, learn tones, and adding your own Simon packs.
Added an autopilot option in the main menu. You can have the game automaticly play for you, and let it fail at random.
Added a basic score system to the game. You will here the total score you got upon failing a round.
Fixed difficulty option scaling.
Added difficulty options to the game. This controls how fast the game tones play, along with how rappidly it speeds up when playing, and failling.
Updated the logo sound to be fadable when the enter key is pressed.
Fixed a bunch of bugs with menus, and replaced the old system with a much more reliable one.
Added a dynamic pack system to the game. You can now add any type of simon game you want to play.
