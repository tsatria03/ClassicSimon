Welcome to my classic simon game! This is just a mini simon game I made as my first project.

When you open the game, a logo will appear. press enter to skip it if you wish. You will then have a tiny menu with just 2 options. Play, and exit.
In the play menu, you can choose between 2 simons. Little pocket simon, and simon karabiner. These are submenus.
In each submenu, there is a start game option, and a learn tones option. You can learn the tones of each simon game by pressing your arrow keys.
The game itself is self explanitory. When it plays a tone, you press the arrow that goes with that tone, and it will add more as the game progresses and so on.

Good luck, and have fun!
